🚀 Modul Praktikum: Memahami .gitignore

Langkah 1 dari 6

1. Membuat File Rahasia Percobaan

Pertama-tama, pastikan kamu berada di dalam folder proyek-pertamaku yang sudah kita buat sebelumnya. Mari kita buat sebuah file bernama .env. File ini biasanya berisi password atau API Key yang sangat terlarang untuk diunggah ke GitHub.

echo "PASSWORD=rahasia123" > .env

Sekarang coba cek status Git kamu:

git status

Kamu akan melihat .env berwarna merah. Artinya, Git bersiap untuk melacak dan mengunggahnya. Gawat!

2. Membuat File .gitignore

Untuk mencegah Git melacak file .env, kita harus mendaftarkannya ke dalam file ajaib bernama .gitignore (titik gitignore).

Mari kita buat file .gitignore dan langsung isi dengan teks .env di dalamnya:

echo ".env" > .gitignore

3. Melihat Keajaiban .gitignore

Sekarang, coba jalankan lagi perintah status:

git status

Ajaib, kan? 🎉 File .env sekarang menghilang dari daftar merah! Sebagai gantinya, Git mendeteksi adanya file baru bernama .gitignore.

4. Menambahkan Aturan Tambahan

File .gitignore bisa diisi banyak aturan sekaligus. Misalnya kita ingin mengabaikan seluruh folder bernama node_modules (folder bengkak bawaan Node.js) dan semua file yang berakhiran .log.

Kita akan menggunakan tanda >> (dua kurung siku) agar teksnya ditambahkan ke baris bawah, bukan menghapus teks sebelumnya:

echo "node_modules/" >> .gitignore
echo "*.log" >> .gitignore

5. Cek Isi File .gitignore

Untuk memastikan aturan-aturan tersebut sudah masuk ke dalam file, kita bisa membacanya menggunakan perintah cat (atau membukanya di Text Editor/VS Code):

cat .gitignore

Seharusnya terminalmu akan menampilkan tiga baris: .env, node_modules/, dan *.log.

6. Simpan File .gitignore

Meskipun file rahasianya tidak kita simpan, file .gitignore itu sendiri wajib kita simpan dan kita push ke GitHub agar teman satu tim kita juga memiliki aturan perlindungan yang sama.

Gunakan perintah andalan kita untuk memasukkan dan menyimpan perubahan:

git add .
git commit -m "Menambahkan .gitignore untuk melindungi file rahasia"

Lalu dorong ke GitHub:

git push origin main

Selesai! Sekarang repositorimu aman dari kebocoran data rahasia.
