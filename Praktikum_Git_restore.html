🚀 Modul Praktikum: Git Restore

Pahami konsepnya di sebelah kiri, dan praktikkan perintahnya di sebelah kanan.

📚 Materi & Konsep

Perintah git restore hadir sejak Git 2.23 untuk menggantikan sebagian fungsi git checkout. Fungsinya sangat spesifik: membatalkan perubahan pada file.

Visualisasi Git Area

Perhatikan dari mana dan ke mana file Anda dikembalikan saat menggunakan Git Restore:

📁 3. Local Repository (HEAD) Kondisi file yang sudah aman di-commit.
📦 2. Staging Area (Index) File yang sudah di-add tapi belum di-commit.
💻 1. Working Directory Folder tempat Anda mengetik/mengedit file saat ini.
  • git restore menarik data dari Staging kembali ke Working Directory.
  • git restore --staged menarik data dari Local Repo kembali ke Staging Area.

💻 Praktikum Step-by-Step

Langkah 1 dari 4

1. Membatalkan Perubahan (Belum di-Stage)

Misalkan Anda mengedit index.html (Working Directory) tapi kodenya malah error. Anda belum melakukan git add. Untuk membatalkan editan tersebut dan kembali ke kondisi terakhir:

git restore index.html

Jika ingin membatalkan perubahan pada semua file di folder saat ini:

git restore .

⚠️ Hati-hati! Kode yang belum disave ke Git akan hilang permanen.

2. Membatalkan git add (Unstaging)

Anda tidak sengaja melakukan git add rahasia.txt sehingga file masuk ke Staging Area. Untuk menurunkannya kembali ke Working Directory tanpa menghapus isi kodenya:

git restore --staged rahasia.txt

Untuk menurunkan semua file dari Staging sekaligus:

git restore --staged .

3. Membuang Perubahan Secara Total

File sudah di-stage (Staging Area), tapi Anda berubah pikiran. Anda ingin mengeluarkan file itu dari Staging DAN sekaligus menghapus semua perubahannya agar kembali persis seperti commit terakhir:

git restore --staged --worktree index.html

4. Mengambil File dari Masa Lalu

Anda bisa mengambil versi file dari commit terdahulu tanpa me-reset seluruh proyek. Ambil style.css dari 2 commit yang lalu:

git restore --source HEAD~2 style.css

Atau menggunakan ID Hash Commit spesifik:

git restore --source 1a2b3c4 app.js

🎉 Selamat! Praktikum Selesai!
