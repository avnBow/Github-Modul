🚀 Modul Praktikum: Setup Git & Konfigurasi SSH

Langkah 1 dari 7

1. Instalasi Git

Pastikan Git sudah terinstal di komputermu:

  • Windows: Unduh dari git-scm.com, install seperti biasa (Next sampai selesai).
  • Mac: Buka terminal dan ketikkan brew install git, atau unduh installer resmi.
  • Linux (Ubuntu): Buka terminal dan jalankan sudo apt install git.

2. Verifikasi Instalasi Git

Buka Terminal (Mac/Linux) atau Git Bash (Windows). Ketikkan perintah ini (ingat, ketik manual, dilarang copas!):

git --version

3. Konfigurasi Identitas (Username & Email)

Masukkan namamu dan email yang terdaftar di akun GitHub:

git config --global user.name "Nama Lengkap Kamu"
git config --global user.email "email.kamu@example.com"

4. Cek SSH Key yang Sudah Ada

Sebelum membuat kunci baru, kita pastikan dulu kamu belum punya kunci SSH agar tidak tertimpa. Jalankan perintah ini:

ls -al ~/.ssh

Jika muncul pesan error atau tidak ada file bernama id_ed25519.pub / id_rsa.pub, artinya aman. Lanjut ke langkah berikutnya. Jika file tersebut sudah ada, kamu bisa mengabaikan Langkah 5 dan langsung ke Langkah 6.

5. Membuat (Generate) SSH Key Baru

Jika kamu belum memiliki kunci SSH, buat "kunci" unik untuk komputermu dengan perintah di bawah ini. Tekan Enter terus-menerus saat diminta lokasi file dan *passphrase* (biarkan *default* dan kosong).

ssh-keygen -t ed25519 -C "email.kamu@example.com"

6. Memasang SSH Key ke Akun GitHub

Tampilkan isi kunci (public key) kamu di layar terminal menggunakan perintah:

cat ~/.ssh/id_ed25519.pub

Langkah manual: Blok dan Copy hasil tulisan yang muncul di dalam terminalmu (dimulai dari tulisan ssh-ed25519...). Kemudian buka browser, masuk ke akun GitHub → Settings → SSH and GPG keys → New SSH key. Paste kodenya di sana dan Save!

*Catatan: Jika di Langkah 4 kamu menemukan file bernama id_rsa.pub, maka ganti perintah cat di atas menjadi cat ~/.ssh/id_rsa.pub

7. Tes Koneksi SSH ke GitHub

Sekarang, mari kita buktikan apakah konfigurasi SSH kamu sudah berhasil terhubung dengan GitHub. Jalankan perintah tes koneksi berikut di terminalmu:

ssh -T git@github.com

Jika muncul pertanyaan (Are you sure you want to continue connecting?), ketik yes lalu Enter.

Berhasil! Jika kamu melihat pesan yang berbunyi "Hi username! You've successfully authenticated, but GitHub does not provide shell access.", artinya komputermu sudah sukses tersambung ke GitHub dengan aman.
