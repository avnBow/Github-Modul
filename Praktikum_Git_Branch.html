🚀 Modul Praktikum: Git Branch & Merge

(Mode Hardcore: Anti Copy-Paste. Wajib Ketik Manual!)

📚 Materi & Konsep

Dalam pengembangan software, kita seringkali perlu membuat fitur baru atau bereksperimen tanpa merusak kode utama. Di sinilah Branching berfungsi.

Bayangkan branch seperti semesta paralel. Anda bisa mengedit kode di semesta tersebut, dan jika sudah sempurna, Anda menggabungkannya kembali ke semesta utama (Merge).

💻 Praktikum Step-by-Step

Langkah 1 dari 5

1. Persiapan & Membuat Branch

Mari kita buat repositori baru dan inisialisasi commit pertama. Ketik perintah berikut secara berurutan: 

mkdir latihan-branch 
cd latihan-branch 
git init echo "Halaman Utama" > index.html 
git add index.html 
git commit -m "Commit Pertama diMain"

Sekarang, buat cabang (branch) baru bernama fitur-login dan langsung berpindah ke cabang tersebut:

git switch -c fitur-login
Catatan: git switch -c adalah cara modern untuk menggantikan git checkout -b. Perintah ini sekaligus membuat branch dan berpindah ke dalamnya.

2. Bekerja di Dalam Branch

Anda sekarang berada di "semesta paralel". Mari kita buat file baru khusus untuk fitur ini: 

echo "Halaman Login Keren" > login.html 
git add login.html 
git commit -m "Menambahkan halaman login"

Coba cek isi folder Anda dengan perintah ls (di Mac/Linux) atau dir (di Windows). Anda akan melihat ada file index.html dan login.html.

3. Berpindah Kembali ke Main

Fitur login sudah selesai dikerjakan di cabangnya. Mari kita kembali ke jalur utama (main atau master):

git switch main
Keajaiban Git:
Coba cek lagi isi folder Anda (ketik ls atau dir). File login.html menghilang! Jangan panik, file tersebut aman berada di dimensi branch fitur-login dan belum ada di branch main.

4. Menggabungkan Branch (Merge)

Sekarang, saatnya menarik kode yang sudah matang dari cabang fitur-login untuk digabungkan ke cabang main yang aktif saat ini.

git merge fitur-login

Periksa lagi folder Anda. Tara! File login.html sekarang sudah muncul di cabang utama.

Fast-forward Merge: Git akan mendeteksi bahwa cabang main belum berubah sejak branch dibuat, sehingga ia cukup memajukan pointer ke depan (fast-forward).

5. Menghapus Branch (Opsional)

Karena fitur sudah berhasil di-merge dengan selamat, cabang fitur-login sudah tidak dibutuhkan lagi. Praktik terbaik adalah menghapusnya agar rapi:

git branch -d fitur-login

Untuk melihat daftar branch yang tersisa, Anda bisa mengetik:

git branch

Selamat! Anda telah menguasai semesta paralel Git! 🚀
