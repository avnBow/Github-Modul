🚀 Modul Praktikum: Membuat Repo & Push ke GitHub

Langkah 1 dari 6

1. Buat Repository Kosong di GitHub

Langkah pertama dilakukan melalui browser, bukan terminal:

  1. Buka github.com dan pastikan sudah login.
  2. Klik tombol hijau New atau ikon + di pojok kanan atas lalu pilih New repository.
  3. Isi Repository name (misal: proyek-pertamaku).
  4. Biarkan pilihan Public/Private sesuai keinginanmu.
  5. PENTING: Jangan centang Add a README file, .gitignore, atau license. Biarkan repository benar-benar kosong!
  6. Klik tombol hijau Create repository.

2. Inisialisasi Repository Lokal

Sekarang buka Terminal (Mac/Linux) atau Git Bash (Windows). Kita akan membuat folder lokal dan mengubahnya menjadi repository Git.

Buat folder baru (samakan namanya dengan di GitHub agar tidak bingung):

mkdir proyek-pertamaku

Masuk ke dalam folder tersebut:

cd proyek-pertamaku

Jadikan folder ini sebagai repository Git:

git init

3. Membuat File dan Melakukan Commit

Mari kita buat dua file percobaan. Kita akan menggunakan git add . untuk memasukkan semua file sekaligus ke dalam staging area tanpa perlu menyebutkan namanya satu-satu.

Buat file README.md dan index.html (bisa diketik via terminal, atau buat manual pakai text editor):

echo "# Halo GitHub!" > README.md
echo "<h1>Proyek Pertamaku</h1>" > index.html

Tambahkan semua file tersebut agar dilacak oleh Git (tanda titik . berarti direktori saat ini):

git add .

Simpan perubahan (commit) dengan pesan yang jelas:

git commit -m "Commit pertamaku: menambahkan file README dan index"

4. Menyesuaikan Nama Branch Utama

Secara bawaan (default), Git versi lama menamai cabang utamanya dengan master. Namun, standar GitHub sekarang menggunakan main. Mari kita ubah agar selaras!

git branch -M main

5. Menambahkan Remote GitHub (SSH)

Git lokalmu belum tahu mau dikirim ke mana file-filenya. Kita harus menambahkan "alamat tujuan" (remote) repository GitHub yang kamu buat di Langkah 1.

Karena kita sebelumnya sudah menggunakan SSH, kita gunakan alamat versi SSH. (Ganti username dengan username akun GitHub-mu, dan proyek-pertamaku dengan nama repomu!)

git remote add origin git@github.com:username/proyek-pertamaku.git

Untuk mengecek apakah alamat sudah masuk, ketik perintah ini:

git remote -v

6. Push (Dorong) Kode ke GitHub

Langkah terakhir! Mari kita dorong commit lokal kita menuju server GitHub.

git push -u origin main

Selamat! 🎉 Coba buka kembali halaman GitHub-mu di browser dan refresh. File README.md dan index.html yang kamu buat sekarang sudah nangkring dengan cantik di sana!
